# OnlineBookStore
Create an online store where a customer can browse, select and purchase books. 

Download the whole application Code. 
Download dependency by this command :- **npm i --legacy-peer-deps**   
Run the application in local :- ** npm run dev**
Local URL will come, Run the url in browser and use this application.
I covered the unit test also for all the code.
Run command to run Unit test :- npm test  
and checking the Coverage run the command:- npm run test:coverage
